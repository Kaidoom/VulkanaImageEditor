Редактор изображений, созданный прежде всего для Linux, с нативными сборками для
Windows: рисование, ретушь и работа с многослойными композициями в рабочей среде Qt
с холстом, ускоряемым Vulkan.

![Рабочая среда Vulkana с многослойным изображением, наборами кистей и коррекциями](../../res/Preview.png)

## Возможности

- **Работа со слоями:** растровые слои, редактируемый текст и фигуры; растровые маски,
  папки, группы обтравочных масок, множественное выделение, режимы наложения,
  дублирование, объединение и растеризация по команде пользователя.
- **Рисование и ретушь:** кисти с чувствительностью к нажиму, процедурные и текстурные
  наборы, ластик, заливка, локальное размытие, штамп клонирования, восстанавливающая
  кисть и автоматическая точечная восстанавливающая кисть.
- **Выделения:** прямоугольник, эллипс, свободное/многоугольное/магнитное лассо,
  выделение по цвету и быстрое выделение с помощью кисти; расширение/сжатие,
  инверсия и повторное выделение.
- **Выделение объектов и уточнение:** выделение объекта приблизительным прямоугольником
  с помощью встроенной автономной модели; уточнение выделений и растровых масок
  с предварительным просмотром в реальном времени и ручными исправлениями.
  Для выделения объектов не требуется скачивать модель или устанавливать Python.
- **Трансформации:** перемещение, масштабирование, вращение, отражение и искажение
  по углам; трансформация границ выделения или выделенных пикселей с привязкой
  и направляющими выравнивания.
- **Неразрушающие коррекции:** коррекции отдельных слоёв и корректирующие слои с масками
  и областью действия Все нижележащие / Эта группа; экспозиция, уровни, кривые,
  цветовой тон/насыщенность, сочность, цветовой баланс, теплота/оттенок,
  монохромное преобразование и инверсия.
- **Фильтры и эффекты слоёв:** размытие по Гауссу, в движении и через объектив;
  обводка, внешняя/внутренняя тень, внешнее/внутреннее свечение, наложение цвета,
  наложение градиента и тиснение со скосом.
- **Несколько документов:** вкладки с независимыми историей, выделениями и состоянием
  просмотра, а также копирование редактируемых слоёв между документами.
- **Импорт PSD:** преобразование с возможностью проверки в собственные слои приложения,
  форматированный текст, простые фигуры, растровые маски, обтравочные группы и поддерживаемые
  стили; использование сохранённого растра при необходимости явно указывается.
- **Экспорт PSD:** многослойный или сведённый результат, редактируемые текст/фигуры/маски
  и обтравка там, где они поддерживаются, с возможностью проверки преобразований
  и заново сформированным сводным изображением.
- **Импорт PDF:** выбранные страницы с заданным PPI в виде растровых слоёв или отдельных
  документов с прозрачным либо белым фоном.
- **Экспорт PDF:** сводное изображение или слои/группы в виде страниц, произвольный выбор
  страниц, размеры холста или по содержимому и выделяемый текст там, где он поддерживается.
- **Рабочая среда и сохранение:** закрепляемые панели с вкладками, Навигатор с управлением
  перемещением и масштабом, темы, настраиваемые сочетания клавиш, линейки, пиксельный
  предпросмотр, собственные проекты `.vulkana` и экспорт PNG/JPEG/WebP.
- **Языки:** 16 языков интерфейса, выбираемых в Настройки → Общие → Язык без перезапуска.
  Все языковые версии предварительные; приглашаем всех к проверке и исправлениям.

Активно разрабатываемая бета-версия. Сохраняйте резервные копии важных проектов.

## Сборка и запуск

Сборки для Linux и Windows рассчитаны на x86-64. Клонируйте репозиторий,
затем выполните команды для своей платформы из его корня:

```sh
git clone https://github.com/Kaidoom/VulkanaImageEditor.git
cd VulkanaImageEditor
```

### Linux

Необходимы Linux, компилятор C++20, Ninja, pkg-config и следующие библиотеки для разработки:

- CMake **3.28+** для входящих в репозиторий предустановок сборки.
- Qt **6.8+**: Core, Gui, Widgets, Network, DBus и PDF; Qt Test для тестов.
- Qt Linguist `lrelease` и Python 3 для сборки языковых пакетов (только инструменты сборки).
- Библиотека разработки qpdf **11+** (импорт/экспорт PDF; не утилита командной строки).
- Библиотека разработки, совместимая с zlib (ZIP-каналы PSD).
- Заголовки и загрузчик Vulkan **1.2+**, работающий драйвер Vulkan и `glslc`.
- minizip-ng **4.x** (модуль pkg-config `minizip`, а не устаревший minizip).
- libwebp и libwebpmux **1.2+**.

Установите платформенные плагины Qt для своего рабочего стола, поддержку SVG и плагины
форматов изображений. Укажите путь к установленному Qt в `CMAKE_PREFIX_PATH`, если он
находится вне системных путей поиска.
Во многих дистрибутивах Qt PDF поставляется отдельным пакетом разработки (например,
`qt6-qtpdf-devel` в Fedora, `qt6-pdf-dev` в Ubuntu). Для работы Vulkana браузер WebEngine
не требуется.
Инструменты Qt Linguist предоставляются пакетом `qt6-linguist` в Fedora или
`qt6-tools-dev-tools` в Ubuntu. При необходимости задайте `-DVULKANA_LRELEASE=/path/to/lrelease`.
Каталоги переводов стандартных диалогов Qt входят в `qt6-qttranslations` в Fedora
или `qt6-translations-l10n` в Ubuntu. О сборке только языковых пакетов и их проверке
читайте в [документации по локализации](../LOCALIZATION.md).

Из корня репозитория:

```sh
cmake --preset release -DIMAGEEDITOR_BUILD_TESTS=OFF
cmake --build --preset release --parallel
./build/release/src/app/imageeditor
```

Проекты и изображения также можно передать в качестве аргументов:

```sh
./build/release/src/app/imageeditor "project.vulkana" "photo.webp"
```

Qt выбирает Wayland или X11 в зависимости от сеанса. Настройки и пользовательские
наборы хранятся отдельно для каждого пользователя. Сетевые службы необязательны;
без [настройки служб](../../config/SERVICES.md) обновления и отправка отзывов
остаются отключёнными.

Для тестов Release включите тестовые цели и пересоберите проект:

```sh
cmake --preset release -DIMAGEEDITOR_BUILD_TESTS=ON
cmake --build --preset release --parallel 6
ctest --preset release
```

Предустановка debug также доступна. Проверки нативного рендеринга требуют слоёв валидации Vulkan.
Некоторым тестам взаимодействия нужен работающий рабочий стол Wayland/X11.

### Windows

Установите инструменты, перечисленные в [руководстве по сборке для Windows](../../tools/windows/README.md#prerequisites).
Откройте Windows PowerShell в корне репозитория, затем соберите и запустите приложение:

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File tools/windows/Build.ps1
C:\Dev\Vulkana\stage\bin\imageeditor.exe
```

Скрипт подготавливает зависимости и создаёт сборку Release с языковыми пакетами.
В руководстве описаны [настройка путей сборки](../../tools/windows/README.md#configuration),
[тесты](../../tools/windows/README.md#testing) и
[создание папки с переносной версией](../../tools/windows/README.md#portable-folder).

## Архитектура

- `src/core` — независимые от платформы документы, слои, геометрия, алгоритмы обработки
  изображений и транзакции с поддержкой отмены.
- `src/render` — общий холст Vulkan, композиция, наложения и ограниченные по размеру кеши GPU.
- `src/ui` — панели Qt, инструменты, вкладки документов, подготовка текста/фигур и файловый ввод-вывод.
- `src/platform` — поиск ресурсов, интеграция с рабочим столом и необязательные службы.
- `src/app` — точка входа приложения; `shaders` — исходный код шейдеров Vulkan.

Каждый документ хранит собственные содержимое и историю; вкладки используют общую
рабочую среду и один рендерер Vulkan. Редактируемые исходные данные отделены от кешей
рендеринга. Холст, пиксельный предпросмотр и экспорт используют одинаковые правила композиции.

См. [документацию для разработчиков](../README.md) и [руководство по архитектуре](../ARCHITECTURE.md).

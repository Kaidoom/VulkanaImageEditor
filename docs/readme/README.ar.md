محرر صور مصمم أساسًا لنظام Linux، للرسم والتنقيح وتركيب الصور باستخدام الطبقات،
مع مساحة عمل مبنية على Qt ولوحة رسم مسرّعة بواسطة Vulkan.

![مساحة عمل Vulkana مع صورة متعددة الطبقات وإعدادات مسبقة للفرش وتعديلات](../../res/Preview.png)

## الميزات

- **التحرير باستخدام الطبقات:** طبقات نقطية ونصوص وأشكال قابلة للتحرير؛ أقنعة نقطية،
  ومجلدات، ومجموعات أقنعة القص، وتحديد متعدد، وأنماط مزج، وتكرار، ودمج، وتحويل
  صريح إلى طبقات نقطية.
- **الرسم والتنقيح:** فرش حساسة للضغط، وإعدادات مسبقة إجرائية وبملمس، وممحاة،
  وتعبئة، وتمويه موضعي، وختم الاستنساخ، وفرشاة المعالجة، والمعالجة الموضعية التلقائية.
- **التحديدات:** مستطيل وقطع ناقص وتحديد حر أو مضلع أو مغناطيسي، وتحديد حسب اللون
  وتحديد سريع موجّه بالفرشاة، مع توسيع التحديد وتقليصه وعكسه واستعادته.
- **تحديد الكائنات وتحسين التحديد:** تحديد كائن برسم مستطيل تقريبي حوله باستخدام
  النموذج المرفق الذي يعمل دون اتصال؛ تحسين التحديدات والأقنعة النقطية مع معاينة
  فورية وتصحيحات يدوية. لا يتطلب تحديد الكائنات تنزيل نموذج أو تثبيت Python.
- **التحويلات:** النقل والتحجيم والتدوير والقلب والتشويه من الزوايا؛ تحويل حدود
  التحديد أو البكسلات المحددة، مع الالتقاط وأدلة المحاذاة.
- **تعديلات غير إتلافية:** تصحيحات لكل طبقة وطبقات تعديل بأقنعة، بنطاق يشمل كل ما
  أسفلها أو هذه المجموعة؛ التعريض والمستويات والمنحنيات ودرجة اللون/التشبع والحيوية
  وتوازن الألوان والدفء/الصبغة والتحويل إلى أحادي اللون وعكس الألوان.
- **المرشحات وتأثيرات الطبقات:** التمويه الغاوسي وتمويه الحركة وتمويه العدسة؛
  الحدود والظل الخارجي/الداخلي والتوهج الخارجي/الداخلي وتراكب اللون وتراكب التدرج
  والشطف والنقش البارز.
- **مستندات متعددة:** تبويبات لها سجل وتحديدات وحالة عرض مستقلة، مع نسخ الطبقات
  القابلة للتحرير بين المستندات.
- **استيراد PSD:** تحويل قابل للمراجعة إلى طبقات أصلية ونص منسق وأشكال بسيطة وأقنعة
  نقطية ومجموعات قص وأنماط مدعومة، مع توضيح الحالات التي يُستخدم فيها التمثيل
  النقطي المحفوظ كبديل.
- **تصدير PSD:** إخراج متعدد الطبقات أو مسطّح، ونصوص/أشكال/أقنعة قابلة للتحرير وقص
  حيثما كان ذلك مدعومًا، مع تحويلات قابلة للمراجعة وصورة مركّبة مُنشأة من جديد.
- **استيراد PDF:** استيراد الصفحات المحددة بقيمة PPI التي تختارها، كطبقات نقطية
  أو مستندات منفصلة، بخلفيات شفافة أو بيضاء.
- **تصدير PDF:** تصدير صورة مركّبة أو طبقات/مجموعات كصفحات، مع اختيار الصفحات،
  وأحجام تطابق لوحة الرسم أو تلائم المحتوى، ونص قابل للتحديد حيثما كان ذلك مدعومًا.
- **مساحة العمل والإخراج:** لوحات قابلة للإرساء ذات تبويبات، ومستكشف بعناصر تحكم
  للتحريك والتكبير، وسمات، واختصارات قابلة للتحرير، ومساطر، ومعاينة البكسلات،
  ومشاريع <bdi dir="ltr">`.vulkana`</bdi> الأصلية، وتصدير PNG/JPEG/WebP.
- **اللغات:** 16 لغة للواجهة، يمكن اختيارها من التفضيلات ← عام ← اللغة دون إعادة
  التشغيل. الترجمات الجديدة أولية؛ نرحب بالتصحيحات.

نسخة تجريبية قيد التطوير النشط. احتفظ بنسخ احتياطية من مشاريعك المهمة.

## البناء والتشغيل

يلزم نظام Linux ومترجم يدعم C++20 وNinja وpkg-config ومكتبات التطوير التالية:

- CMake <bdi dir="ltr">**3.28+**</bdi> لاستخدام إعدادات البناء المسبقة المرفقة.
- Qt <bdi dir="ltr">**6.8+**</bdi>: Core وGui وWidgets وNetwork وDBus وPDF؛ وQt Test للاختبارات.
- Qt Linguist `lrelease` وPython 3 لبناء حزم اللغات (أدوات للبناء فقط).
- مكتبة تطوير qpdf <bdi dir="ltr">**11+**</bdi> (لاستيراد وتصدير PDF؛ وليست أداة سطر الأوامر).
- مكتبة تطوير متوافقة مع zlib (لقنوات ZIP في PSD).
- ملفات الترويسات ومحمّل Vulkan <bdi dir="ltr">**1.2+**</bdi>، وبرنامج تشغيل Vulkan يعمل، و`glslc`.
- minizip-ng <bdi dir="ltr">**4.x**</bdi> (وحدة pkg-config المسماة `minizip`، وليست مكتبة minizip القديمة).
- libwebp وlibwebpmux <bdi dir="ltr">**1.2+**</bdi>.

ثبّت إضافات المنصة الخاصة بـQt الملائمة لسطح مكتبك، ودعم SVG، وإضافات تنسيقات الصور.
وجّه `CMAKE_PREFIX_PATH` إلى تثبيت Qt إذا كان خارج مسارات البحث الخاصة بالنظام.
يأتي Qt PDF في حزمة تطوير منفصلة في كثير من التوزيعات (مثل `qt6-qtpdf-devel` في
Fedora و`qt6-pdf-dev` في Ubuntu). لا يتطلب متصفح WebEngine لتشغيل Vulkana.
توفر حزمة `qt6-linguist` في Fedora أو `qt6-tools-dev-tools` في Ubuntu أدوات Qt Linguist.
اضبط <bdi dir="ltr">`-DVULKANA_LRELEASE=/path/to/lrelease`</bdi> عند الحاجة.
تأتي فهارس ترجمة مربعات الحوار القياسية في Qt من حزمة `qt6-qttranslations` في Fedora
أو `qt6-translations-l10n` في Ubuntu. راجع [وثائق الترجمة](../LOCALIZATION.md)
لبناء حزم اللغات وحدها ومراجعتها.

من المجلد الجذر للمستودع:

<div dir="ltr">

```sh
cmake --preset release -DIMAGEEDITOR_BUILD_TESTS=OFF
cmake --build --preset release --parallel
./build/release/src/app/imageeditor
```

</div>

يمكن أيضًا تمرير المشاريع والصور كوسائط:

<div dir="ltr">

```sh
./build/release/src/app/imageeditor "project.vulkana" "photo.webp"
```

</div>

يختار Qt بين Wayland وX11 بحسب الجلسة. تُحفظ التفضيلات والإعدادات المسبقة المخصصة
في مساحة تخزين خاصة بكل مستخدم. الخدمات عبر الإنترنت اختيارية؛ من دون
[تهيئة الخدمات](../../config/SERVICES.md)، تظل التحديثات وإرسال الملاحظات معطّلة.

للتطوير والاختبار:

<div dir="ltr">

```sh
cmake --preset debug
cmake --build --preset debug --parallel
ctest --preset debug
```

</div>

تحتاج فحوص التصيير في وضع التصحيح والتصيير الأصلي إلى طبقات التحقق من Vulkan.
وتتطلب بعض اختبارات التفاعل جلسة سطح مكتب Wayland/X11 قيد التشغيل.

## البنية

- `src/core` — المستندات والطبقات والهندسة وخوارزميات الصور والمعاملات القابلة للتراجع،
  بصورة مستقلة عن المنصة.
- `src/render` — لوحة رسم Vulkan المشتركة، والتركيب، والتراكبات، وذاكرات تخزين مؤقت
  محدودة الحجم على GPU.
- `src/ui` — لوحات Qt والأدوات وتبويبات المستندات وتجهيز النصوص/الأشكال وقراءة الملفات وكتابتها.
- `src/platform` — البحث عن الموارد والتكامل مع سطح المكتب والخدمات الاختيارية.
- `src/app` — نقطة دخول التطبيق؛ `shaders` — الشيفرة المصدرية لمظللات Vulkan.

يملك كل مستند محتواه وسجله؛ وتتشارك التبويبات مساحة عمل واحدة ومصيّر Vulkan واحدًا.
تبقى البيانات المصدرية القابلة للتحرير منفصلة عن ذاكرات التخزين المؤقت للتصيير.
تستخدم لوحة الرسم ومعاينة البكسلات والتصدير قواعد التركيب نفسها.

راجع [وثائق المطورين](../README.md) و[دليل البنية](../ARCHITECTURE.md).

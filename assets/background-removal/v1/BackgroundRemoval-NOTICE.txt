BiRefNet-lite INT8
-----------------
BiRefNet, Copyright (c) 2024 ZhengPeng.
512×512 ONNX conversion, Copyright (c) 2026 Studio Ludens V.O.F.
Both copyright notices and the MIT permission text are in BiRefNet-LICENSE.txt.
Upstream model and implementation:
https://huggingface.co/ZhengPeng7/BiRefNet_lite
https://github.com/ZhengPeng7/BiRefNet
Source ONNX conversion:
https://huggingface.co/studioludens/birefnet-lite-512
Revision 962e67969ec6acec9c19fab76acee4f5e22e990c, onnx/model.onnx.
The conversion's model card explicitly includes the ONNX weights under MIT.

Vulkana modifies that FP32 graph with calibrated, per-channel signed INT8
weights and signed INT8 activation ranges for Conv, constant-weight MatMul and
Gemm operations (ONNX QuantizeLinear/DequantizeLinear). Other operations remain
floating-point; the input and output tensors are FP32. No fine-tuning is used.
A subsequent graph rewrite reduces intermediate transposes and accumulation
buffers in 20 deformable-convolution interpolation blocks. It keeps the
quantized weights/scales and interpolation arithmetic/order unchanged. This is
a derived artifact, not an upstream INT8 release. Exact payload hashes and
conversion settings are recorded in provenance.json.

Runtime and redistribution
--------------------------
Both models execute locally through the ONNX Runtime CPU library already
bundled for Object Selection. Its MIT license and full upstream third-party
notices accompany that runtime. No image upload, first-use model download,
Python or PyTorch runtime is required.

Keep this notice and the accompanying license files with the model artifacts.

by upstream authors is implied.

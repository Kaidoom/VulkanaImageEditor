# Built-in brush preset assets

These versioned text records are the checked-in representation of every
built-in preset. Each preset references
stable tip and grain asset IDs; presets do not map to preset-specific C++
classes. The generated Dry Ink mask and paper grain are deterministic built-in
resources and contain no third-party brush-pack content.

All built-in records default to follow-stroke rotation. The Direction toggle
can switch to a fixed tip angle without changing the preset's other settings;
Save Copy preserves that explicit choice.
